Card Schema Reference

Required

type: Creature, Instant, Sorcery, Enchantment, Artifact, Planeswalker, Land, Battle, Kindred

Identity

cost: Mana cost — {1}{W}, {X}{R}{R}, {W/U} (hybrid), {R/P} (Phyrexian)
supertype: Legendary, Basic, Snow
subtype: Creature type, land type, etc. — Human, Angel, Equipment, Aura, Plains

Stats

p/t: Power / toughness — 2 / 3
loyalty: Starting loyalty for planeswalkers — 4

Rules Text (auto-translated)

rules: Natural language — auto-generates effects, keywords, triggers, and activated abilities

Explicit DSL (optional overrides)

keywords: flying, trample, first_strike, deathtouch, lifelink, vigilance, haste, hexproof, menace, defender, flash, reach, indestructible, prowess, ...
effect: damage(), draw(), gain_life(), destroy(), exile(), bounce(), pump(), counter(), mill(), scry(), create_token(), add_mana(), add_counter(), tap(), sacrifice(), add_keyword(), x_damage() — Targets: target(creature), target(creature, opponent), target(creature, attacking), all(creature), all(creature, attacking)
when(event): Triggered ability — enters_battlefield, dies, attacks, blocks, cast, gain_life, begin_upkeep, end_step, ...
activate(cost): Activated ability — activate({0}): add_mana(G)
loyalty(+/-N): Planeswalker ability — loyalty(+1): draw(1)
enchant: Aura target type — creature, artifact, permanent
equip: Equipment equip cost — {2}
replace(event): Replacement effect — enter_tapped, add_counters(), prevent, prevent_damage()
